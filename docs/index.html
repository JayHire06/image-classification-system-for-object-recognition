Question and scope

One image, one label

Each example is one 32 × 32 RGB image with one target label from ten known categories. At prediction time, the classifier receives only the image pixels. It returns scores over the ten classes and selects the highest-scoring label.

The comparison measures the two complete pipelines on CIFAR-10. It cannot isolate how much of the gain comes from ImageNet pretraining, architecture, augmentation, or their combination.

Dataset and quality

60,000 small color images

CIFAR-10 was created by Alex Krizhevsky, Vinod Nair, and Geoffrey Hinton. It contains 6,000 labeled images per class. We keep the official test partition and use seed 42 to divide the official training partition into training and validation. The archive is downloaded from its published source or a checksum-verified mirror. The site includes aggregate results, test indices, and six attributed 32 × 32 test thumbnails. Preprocessing and methods

Local gradients vs. learned features

Classical baseline

HOG + linear SVM

Histograms of oriented gradients summarize edge directions in local cells. Block normalization reduces the influence of contrast. A linear SVM learns a margin-based boundary for each class. This makes a compact baseline for testing how much information local shape alone provides.

We compared four cell-size and regularization combinations. The selected setting uses 4-pixel cells, 1,764 features, and C = 0.1. Sigmoid calibration fits the validation split so the SVM can report class probabilities.

Transfer learning

MobileNetV2

ImageNet weights provide reusable filters for visual structure. We resize to 224 × 224 to use the pretrained backbone at its expected scale and normalize with fixed ImageNet statistics. Random crops and flips apply only during training to vary position and orientation.

We train the ten-class head for two epochs, then fine-tune the last four backbone blocks and head for three. Both stages use Adam and cross-entropy. The learning rate drops from 0.001 to 0.0001.

Method references. Dalal and Triggs, HOG · Sandler et al., MobileNetV2 · Torchvision pretrained weights

Evaluation design

Select settings before final scoring

  1. Tune HOG + SVM within training. Fit on 32,000 examples and rank candidates by macro-F1 on a stratified 8,000-image holdout. Refit the winner on all 40,000 and calibrate on validation.
  2. Select the CNN checkpoint on validation. Save the epoch with the highest validation macro-F1. ImageNet normalization uses published constants, and validation and test receive deterministic transforms.
  3. Score the same official test images. Macro-F1 weights the ten class F1 scores equally and penalizes both missed detections and false alarms. Accuracy counts overall correct predictions. The test set is balanced, so per-class scores and confusion counts show which errors the two overall scores hide.

The first SVM test score was viewed during development before a baseline revision. The revised settings were selected using the training-only holdout above. The official benchmark is therefore a shared held-out evaluation for the final fitted models, with prior test-score exposure in the development history.

Interpretation and limitations

The transfer model wins on this benchmark

MobileNetV2 scored 0.9148 macro-F1 and 91.48% accuracy. HOG + SVM scored 0.5415 macro-F1 and 54.77% accuracy. That is a gain of 0.3733 macro-F1 and 36.71 percentage points of accuracy for the tested pipelines.

Finer HOG cells helped the classical baseline on its internal holdout. The winning trial reached 0.5339 macro-F1 versus 0.5082 for the original setting. Its SVM fit took about 90 seconds versus 30 seconds on the same machine and holdout protocol. The gain required a larger descriptor and a slower fit.

A paired bootstrap resamples the same test examples for both models to estimate uncertainty in their score difference.

Both models most often called cats dogs. HOG + SVM made that error 170 times and MobileNetV2 83 times. MobileNetV2 also assigned more than 99% probability to several wrong answers. These cases illustrate why a large class score alone gives limited evidence of reliability on an individual image.

Each model must pick from the same ten labels, even for an unfamiliar upload. Low-resolution images can be ambiguous, and the benchmark gives no estimate of performance on new cameras, backgrounds, or classes. The bootstrap assumes the test examples are exchangeable and holds the trained weights fixed. It does not measure variability across retraining runs or new image distributions.

Reproduction and sources

Run the study from the source

Use Python 3.11 or newer in an activated virtual environment. Run these commands from the repository root. The archived run used seed 42 and an RTX 4060 Laptop GPU for the CNN, with batch size 128 and two workers. The CPU fallback may produce small numerical differences.

python -m pip install -r requirements.txt
python -m src.dataset
python -m src.train_svm
python -m src.train_cnn --batch-size 128 --num-workers 2
python -m src.evaluate --batch-size 128 --num-workers 2
python -m src.course_report --batch-size 128 --num-workers 2
